# NEON RUSH

Неоновые synthwave-гонки на чистом HTML/JS (без сборки, один файл = одна игра).

## Файлы

| Файл | Что это |
|---|---|
| `neon-rush.html` | Псевдо-3D версия (canvas, проекция сегментов) |
| `neon-rush-3d.html` | Настоящая 3D версия (WebGL, Three.js с CDN) |

## Возможности

- Неоновый танк с пушкой: стрельба (F / J / CTRL), нитро (SHIFT / SPACE)
- Гонка против 5 соперников с живым счётом места (ВОЛЬТ, ФУРИЯ, ВИХРЬ, ГРОМ, НИКС)
- Трафик, обгоны, комбо, чекпоинты, очки/рекорд (localStorage)
- GTA-экшн: розыск со звёздами ★1–5, полиция с мигалками, бочки с цепными взрывами, пикапы `$`, режим «БЕСПРЕДЕЛ ×2»
- Клавиатура + тач-управление, звук (Web Audio)

## Запуск

Просто открыть файл в браузере (двойной клик). Для 3D-версии нужен интернет (three.js грузится с CDN).
